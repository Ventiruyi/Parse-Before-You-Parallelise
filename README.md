# Artifact: Parse Before You Parallelise (anonymized review copy)

Code and measured results for the FPGA 2027 submission
"Parse Before You Parallelise: Semantic Constraints from C Source
Determine Whether HLS-Generated RTL Is Correct". This copy is anonymized
for double-blind review; the public release adds the heavy backend
evidence omitted here.

## Layout

- `paper/code/` C parser / constraint extractor, RTL generator, the
  experiment runners, the PolyBench admission and concretization scanners,
  and the report-asset emitter.
- `paper/results/` measured results as produced by the flows
  (gcc 6.3.0 reference execution, Icarus Verilog 14.0 simulation,
  Yosys + nextpnr-ecp5 + ecppack on Lattice ECP5 LFE5U-25F CABGA256
  speed 6), including per-design logs and PPA manifests.
- `paper/submission/` the manuscript source. Every number in the text
  comes from `numbers.tex`, which is generated by the emitter, never
  hand-edited.

## Requirements

- Python 3.12 for the emitter.
- gcc (MinGW-w64; the reference programs were built with gcc 6.3.0,
  `-O1 -std=c99`) to re-run reference execution.
- Icarus Verilog 14.0 to re-run simulation.
- Yosys + nextpnr-ecp5 + ecppack (oss-cad-suite build; exact versions in
  each `yosys.log` / `nextpnr.log` header) to re-run the physical flow.
- PolyBench/C 4.2.1 sources (third-party, not bundled) only for
  `run_polybench_admission.py` and `run_polybench_concrete.py`.

## Quick verification (no tools beyond Python needed)

    python paper/code/emit_report_assets.py --root . --submission paper/submission

The emitter re-reads the stored results and regenerates `numbers.tex`,
the five tables, and the two figures. It is deterministic: the rerun
reproduces every staged asset byte-for-byte, and it refuses to write
anything if its assertions (the paper's claims) do not hold.

All other runners are argparse scripts; each documents its own flags via
`--help`.

## What this review copy omits

Post-synthesis netlists (`design.json`, `yosys_design.json`, 569 MB),
bitstreams and config images (`design.bit`, `design.config`, 70 MB),
compiled simulators (`sim.vvp`), and reference binaries (`*.exe`) are
omitted to keep the anonymized artifact light; every emitted number is
fully covered by the staged summaries, logs, and manifests. These heavy
artefacts are part of the public release. Absolute local paths embedded
in tool logs and manifests are normalized to `<workspace>` / `<userdir>`;
no measurement content is modified.
